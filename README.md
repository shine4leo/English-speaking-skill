核心能力包括：
- TED 朗读：检索官方近期内容、记录检索时间，进行朗读、跟读与重说；不抓取或保存 TED 全文，遵守其使用政策。
- 分级听力：慢速、自然、快速三档；按信息点检查理解，而不是机械逐字翻译。
- 主题对话：覆盖日常、旅行、面试、工作和观点讨论，每个场景都有角色、目标、意外情况与完成条件。
- 防止 AI 发散：一次只问一个问题，保持当前角色和任务；普通模式每节最多三个重点纠错，纠错后必须让你重说。
- 学习记忆：词组采用同日、1天、3天、7天、14天、30天、60天的复习阶梯。
- 独立日志：每次训练生成一个带时间戳的 Markdown 文件，记录主题、短语、语法、听力、自然表达、发音证据和下次计划。
- 诚实纠音：只有模型确实收到原始音频时才判断发音；只有语音转写时，绝不会假装听出了 /θ/、重音或语调问题。
- 同日两次训练：第二次优先复习第一次的内容，不继续堆新词。
- 并发保护：包含经过测试的日志锁，避免手机和电脑同时训练时覆盖学习记录。
