# English-speaking-skill
可以使用这一套skill去训练自己的英语口语能力

🤣 不知道各位是不是经常遇到自己想练习口语但是苦于在中国很少这种语言环境的问题

这里开发了一个skill 辅助你让你的codex老师教你

对我来说几乎免费🆓

你不需要开各种各样的口语学习

也不需要去ometv这种免费的平台看一群色鬼在哪里种族歧视

更不需要和别人face to face 聊了几嘴一直重复的话，然后人家来一句：wow you english is good！！！ 🤣😂😂

所以直接导入自己的codex 每天给自己10-15min用来练习

可能是自身性格问题，比较外向和社牛，我不把这个工作当作是自己的累赘和每日一定要完成的事情

反而是自己放松的一个有效手段

大二之前口语我很垃圾

大三的时候和外国人经常聊天 口语取得比较大的进步

保送结束出国旅游发现自己的口语能力还差很多

现在呢，继续提升吧，语言，是你见世界的基本工具

很多人认为：ai这么屌学英语没用

实则：当你在外参加学术会议或者和别人做生意，你哑巴英语，人家凭什么chat with you？ 最后顶着手机拍照纪念一下，却丢了一次次机会·····
