# English-speaking-skill

> 
> A Codex Skill for Spoken English Practice

这套 Skill 可以用来系统性训练你的英语口语。

## ✨ 前言

很多国内学习者都会遇到同一个痛点：想要练习口语，但缺少稳定、高质量的语言环境。

于是我做了这个 Skill，借助 Codex 作为你的口语老师，成本几乎免费 🆓。

你不用来回切换一堆口语 App；
不用去随机聊天平台，直面糟糕的体验与偏见；
也不必线下找人闲聊，收获几句客套的 `Wow, your English is good!` 却很难得到有效反馈 🤣。

导入 Codex 之后，每天只需要 10–20 分钟即可开展训练。

对我自己而言，它不是硬性任务，更像是一种放松方式。
大二之前我的口语基础很差；大三和外国人高频交流之后才有明显进步；保送后出国旅行，才意识到依然还有很大提升空间。
语言，是我们认识世界的工具。

不少人觉得：AI 这么强，学英语口语没有意义。
但现实是：学术会议、商务交流里，如果你是 “哑巴英语”，无法实时沟通，再好的翻译工具也帮不住你 —— 很多机会只会白白错过。

## 🚀 核心能力

- **TED 朗读**：检索近期官方内容，记录检索时间，支持朗读、跟读、复述；不会抓取、存储 TED 全文，遵循其使用协议。
- **分级听力**：慢速 / 正常 / 快速三档语速；侧重信息点理解考核，拒绝机械逐字翻译。
- **主题情景对话**：覆盖日常、旅行、面试、职场、观点辩论；每个场景内置角色设定、对话目标、突发分支与完成标准。
- **收敛控制**：单次只抛出一个问题，不跑偏；普通模式单次训练最多 3 条重点纠错，纠错后要求你重新表达。
- **间隔复习记忆**：生词短语按 `同日 → 1天 → 3天 → 7天 → 14天 → 30天 → 60天` 阶梯复习。
- **独立训练日志**：每次训练自动生成带时间戳的 Markdown 日志，记录训练主题、地道短语、语法问题、听力要点、发音记录、后续学习计划。
- **诚实纠音机制**：**仅在收到原始音频时才评估发音**；仅有文本转写结果时，不会幻觉判断 /θ/、单词重音、语调等语音细节。
- **同日多轮训练策略**：同一天第二次训练优先复习上一轮内容，不盲目新增素材。
- **并发安全保护**：内置日志锁机制，防止手机、电脑两端同时训练导致学习记录覆盖丢失。

## 📦 安装部署

将解压后的文件夹放置在路径：

```
<你的工作区>/.agents/skills/spoken-english-coach/
```

Codex 原生支持从 `.agents/skills` 目录加载 Skill。
手机端可使用 Cloud 环境或者连接电脑项目；语音功能可用性取决于客户端、连接状态以及语音服务是否可用。

> 
> 参考文档：Codex Skill 官方文档、Codex 移动端说明、Voice 相关文档

## 🎮 使用示例命令

**首次推荐启动**

```
$spoken-english-coach 开始训练，20分钟，今天练旅行英语。
```

其他常用指令：

```
完整三模块，30分钟
听力，正常速度
面试，产品经理岗位
朗读，帮我选一个近期合适的 TED Talk
严格纠错
结束并保存
```
